# QUAC logo

A top-down view of a duck in flight, drawn from the diagonal element of the QGIS logo: the orange block is the bill, rounded at the tip; the yellow chevron is the face; the bar continues as a black body, with swept wings added either side. Each piece keeps the element's two-face shading, the right-hand face lighter.

| File | Use |
| --- | --- |
| `quac-mark.svg` | The duck alone, on light backgrounds |
| `quac-mark-on-dark.svg` | The duck alone, on dark backgrounds (the black lifted to charcoal so it stays visible) |
| `quac-logo.svg` | Duck and "QUAC" wordmark, on light backgrounds |
| `quac-logo-on-dark.svg` | Duck and wordmark, on dark backgrounds |
| `quac-mark-512.png` | The light-background mark as a 512 × 512 PNG with a transparent background |

The wordmark is Inter Display Bold, converted to outlines so it needs no font installed.

## Colours

| Part | Shaded face | Lit face |
| --- | --- | --- |
| Bill | `#ee7913` | `#f18d36` |
| Face | `#f0e64a` | `#f2ea65` |
| Body | `#161616` | `#383838` |
| Body, on dark | `#3a3a3a` | `#5a5a5a` |

The orange and yellow are the QGIS logo's own; each lit face is the shaded colour with 15% white over it, as in the QGIS element.
