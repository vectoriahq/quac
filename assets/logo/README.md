# QUAC logo

A duck's head seen from above, facing top-left: a rounded orange bill with two nostrils near its base, a yellow chevron, and a rounded warm-brown head. The eyes are on the sides of the head, so each is a dark, lens-shaped eye that stands just proud of the head's outline, with a white highlight. It is drawn from the diagonal element of the QGIS logo, keeping that element's width, its orange and yellow, its chevron, and its two-face shading: each part is split along the middle, and the right-hand half is lighter. The back of the head is rounded with the bill's front curve turned round, and the head is about the same size as the bill.

| File | Use |
| --- | --- |

| `quac-logo.svg` | Head and "QUAC" wordmark, on light backgrounds |

The wordmark is Inter Display Bold, converted to outlines so it needs no font installed.
