QUAC

QUAC (Quite Useful Additions for Catalogs) is a profile of STAC 1.1.0 for describing the layers of a map: where each layer's data comes from, how its fields are filled in and checked, how it is drawn, and how its layers relate.

A QUAC Collection is an ordinary STAC Collection with quac: fields added, so an application can read the fields it knows and ignore the rest.

Read and use it

  • The repository: the spec, the code and the issue tracker.
  • The field reference: every field, with an example.
  • The JavaScript package, @vectoriahq/quac, which writes QUAC catalogues and reads them.
  • The QGIS Server plugin, which serves a QGIS project's catalogue.

The schema

A catalogue says it follows QUAC by listing the schema's address in stac_extensions. Each version keeps its address.
