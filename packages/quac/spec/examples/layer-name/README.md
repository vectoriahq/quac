# `quac:layer_name`

**The QGIS setting:** none to tick. Adding a GeoPackage holding several tables, QGIS asks which to add; this project added the `parks` table.

**What the project file holds:** a data source ending `|layername=parks`: `./open-space.gpkg|layername=parks`.

**What the catalogue says:** the data asset carries `quac:layer_name: "parks"`, the table of the GeoPackage the Collection reads.
