# `quac:mutually_exclusive`

**The QGIS setting:** **Mutually Exclusive Group**, ticked in the Layers panel's right-click menu on the Street furniture group.

**What the project file holds:** `<layer-tree-group name="Street furniture" mutually-exclusive="1">`.

**What the catalogue says:** the group's Catalog, `street-furniture`, has `quac:mutually_exclusive: true`. A group without the tick has no field.
