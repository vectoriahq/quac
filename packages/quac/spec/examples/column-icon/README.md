# `quac:icon` on a column

**The QGIS setting:** a layer variable named `quac_icon_species`, set to `leaf` under **Variables** in the Trees layer's Layer Properties. The variable is Groundwork's own; QGIS's form shows no such icon.

**What the project file holds:** the layer's `variableNames` and `variableValues` custom properties, holding `quac_icon_species` and `leaf`.

**What the catalogue says:** the `species` column has `quac:icon` set to the address of Tabler's `leaf` icon on jsDelivr.
