# `quac:active_collection`

**The QGIS setting:** **Initial active layer** on the QField tab of Project Properties, which the QFieldSync plugin adds. Here it names the Benches layer.

**What the project file holds:** `<properties><qfieldsync><initialActiveLayer>benches_1</initialActiveLayer></qfieldsync></properties>`, the layer's id.

**What the catalogue says:** the top-level Catalog's `quac:active_collection` is `benches_1`, the id of the Collection made from the Benches layer.
