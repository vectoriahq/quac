# `quac:categorised_field`

**The QGIS setting:** **Categorized** chosen on the Symbology tab of the Trees layer's Layer Properties, with **Value** set to the field `species`, saved as the style By species.

**What the project file holds:** `<renderer-v2 type="categorizedSymbol" attr="species">`.

**What the catalogue says:** the Trees Collection's style asset for By species carries `quac:categorised_field: "species"`. Any other kind of style writes no field.
