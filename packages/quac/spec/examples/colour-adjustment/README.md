# `quac:contrast`, `quac:brightness`, `quac:gamma` and `quac:saturation`

**The source:** none. No producer writes these fields; a catalogue's author writes them by hand. This example is such a catalogue: one layer of aerial imagery tiles.

**What the catalogue says:** the Aerial Collection is drawn with its contrast lowered a little (`quac:contrast: -0.1`), then lifted by 0.05 of the way to white (`quac:brightness: 0.05`), then with its mid-tones lightened (`quac:gamma: 1.8`), then with a fifth less colour (`quac:saturation: -0.2`).
