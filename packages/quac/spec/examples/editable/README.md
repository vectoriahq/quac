# `quac:editable` on a Collection

**The QGIS setting:** **Read-only**, ticked for the Trees layer in the Layer Capabilities table on the Data Sources tab of Project Properties.

**What the project file holds:** `<maplayer readOnly="1">`.

**What the catalogue says:** the Trees Collection's `quac:editable` is `false`, the setting reversed. A layer not ticked Read-only gives `true`.
