# `quac:private`

**The QGIS setting:** **Private**, ticked for the Trees layer in the Layer Capabilities table on the Data Sources tab of Project Properties.

**What the project file holds:** `<flags><Private>1</Private></flags>`.

**What the catalogue says:** the Trees Collection's `quac:private` is `true`: the source keeps the layer off its map and legend, as for a table that only feeds a list. A layer that is not private has no field.
