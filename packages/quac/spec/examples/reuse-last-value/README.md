# `quac:reuse_last_value`

**The QGIS setting:** the `species` field's reuse policy set to **Reuse Last Entered Value** on the Attributes Form tab.

**What the project file holds:** `<reuseLastValuePolicy><field name="species" reuseLastValuePolicy="AllowedDefaultOn"/></reuseLastValuePolicy>`.

**What the catalogue says:** the `species` column has `quac:reuse_last_value: true`: a new feature is offered the species last entered.
