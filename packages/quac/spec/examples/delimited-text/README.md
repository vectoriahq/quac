# `quac:delimited_text`

**The QGIS setting:** a CSV file added from **Layer › Add Layer › Add Delimited Text Layer**, with a **Custom delimiters** of `;`, one line skipped before the header, and **No geometry (attribute only table)**.

**What the project file holds:** a `delimitedtext` data source, `file:./species.csv?type=csv&delimiter=;&skipLines=1&geomType=none`.

**What the catalogue says:** the data asset carries `quac:delimited_text` with `delimiter: ";"` and `skip_lines: 1`, and QGIS's defaults for the rest.
