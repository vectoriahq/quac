# `quac:identifiable`

**The QGIS setting:** **Identifiable**, unticked for the Trees layer in the Layer Capabilities table on the Data Sources tab of Project Properties.

**What the project file holds:** `<flags><Identifiable>0</Identifiable></flags>`.

**What the catalogue says:** the Trees Collection's `quac:identifiable` is `false`: its features cannot be identified, and the layer cannot be the active layer. An identifiable layer gives `true`.
