# `quac:max_zoom`

**The QGIS setting:** **Max. Zoom Level** set to 19 in the XYZ connection the OpenStreetMap layer was added from.

**What the project file holds:** a `wms` provider data source with `type=xyz` and `zmax=19`.

**What the catalogue says:** the OpenStreetMap Collection's `quac:max_zoom` is `19`: tiles are requested down to level 19, and enlarged past it.
