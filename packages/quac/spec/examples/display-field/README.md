# `quac:display_field`

**The QGIS setting:** **Display Name** on the Display tab of Layer Properties, set to the field `species`.

**What the project file holds:** `<previewExpression>"species"</previewExpression>`. QGIS saves the display name as an expression; one that names a single field, in double quotes, gives the field.

**What the catalogue says:** the Trees Collection's `quac:display_field` is `species`. A display name that is any other expression gives no field.
