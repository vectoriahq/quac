# `quac:editable` on a column

**The QGIS setting:** **Editable** unticked for the `tree_id` field on the Attributes Form tab of the Trees layer's Layer Properties.

**What the project file holds:** `<editable><field editable="0" name="tree_id"/></editable>`.

**What the catalogue says:** the `tree_id` column has `quac:editable: false`: it is shown, and no one can change it. An editable field has no field.
