# `quac:label_on_top`

**The QGIS setting:** **Label on top** ticked for the `notes` field, and left unticked for `species`, on the Attributes Form tab.

**What the project file holds:** `<labelOnTop><field labelOnTop="0" name="species"/><field labelOnTop="1" name="notes"/></labelOnTop>`.

**What the catalogue says:** the `notes` column has `quac:label_on_top: true`: the form puts its name above its value. The `species` column has no such field.
