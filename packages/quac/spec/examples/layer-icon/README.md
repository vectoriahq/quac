# `quac:icon` on a Collection

**The QGIS setting:** a layer variable named `quac_icon`, set to `tree` under **Variables** in the Trees layer's Layer Properties. The variable is Groundwork's own; QGIS's layer list shows no such icon.

**What the project file holds:** the layer's `variableNames` and `variableValues` custom properties, holding `quac_icon` and `tree`.

**What the catalogue says:** the Trees Collection's `quac:icon` is the address of Tabler's `tree` icon on jsDelivr. A value may also be an `https://` address, used as written, or an icon name in Iconify's `library:icon` form.
