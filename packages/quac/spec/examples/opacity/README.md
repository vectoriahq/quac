# `quac:opacity`

**The QGIS setting:** **Opacity** under Layer Rendering on the Symbology tab of Layer Properties, set to 60 %.

**What the project file holds:** `<layerOpacity>0.6</layerOpacity>`.

**What the catalogue says:** the Trees Collection's `quac:opacity` is `0.6`. QGIS saves an opacity on every layer, so every layer from a project has the field; a fully opaque layer gives `1`.
