# `quac:geometry_type`

**The QGIS setting:** none to set. It is the layer's kind of geometry, here a multi-part line layer.

**What the project file holds:** `<maplayer geometry="Line" wkbType="MultiLineString">`.

**What the catalogue says:** the Trees Collection's `summaries` hold `quac:geometry_type: ["Line"]`, QGIS's name for the kind of geometry, so a multi-part line is `Line`. Beside it, outside QUAC, `vector:geometry_types` lists the GeoJSON type, `MultiLineString`.
