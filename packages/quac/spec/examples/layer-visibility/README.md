# `quac:visibility_checked` on a Collection

**The QGIS setting:** the tick beside the Trees layer in the Layers panel, left unticked.

**What the project file holds:** `<layer-tree-layer checked="Qt::Unchecked">`.

**What the catalogue says:** the Trees Collection's `quac:visibility_checked` is `false`: the layer opens switched off. A ticked layer gives `true`.
